# What this app is

Today this app keeps a single list of items. Each item has a title, an optional
note, and the time it was added. The one screen shows every item newest-first in
a table and carries a small form to add another; everything is stored in a
SQLite file that lives with the app, so the list is still there after a restart.
It is deliberately the smallest thing that works end to end — a screen, a server
function, a table and some components — so that whatever it grows into next is
built the same way.
