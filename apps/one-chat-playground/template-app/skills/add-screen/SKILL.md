# Add a screen

A screen is one file in `src/routes/`. The file name is the URL:
`src/routes/notes.tsx` → `/notes`, `src/routes/notes.index.tsx` → `/notes`,
`src/routes/notes.$id.tsx` → `/notes/:id`. The route tree
(`src/routeTree.gen.ts`) is regenerated by the dev server — never edit it.

## Steps

1. Create the file. Copy the shape of `src/routes/index.tsx`:

   ```tsx
   import { createFileRoute } from "@tanstack/react-router"
   import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"
   import { listNotes } from "@/server/notes"

   export const Route = createFileRoute("/notes")({
     component: NotesScreen,
     loader: () => listNotes(), // omit if the screen reads nothing
   })

   function NotesScreen() {
     const notes = Route.useLoaderData()
     return (
       <main className="mx-auto flex w-full max-w-3xl flex-col gap-6 p-6">
         <Card>
           <CardHeader><CardTitle>Notes</CardTitle></CardHeader>
           <CardContent>{/* shadcn components only */}</CardContent>
         </Card>
       </main>
     )
   }
   ```

2. Make it reachable. Add a `<Link to="/notes">Notes</Link>` (from
   `@tanstack/react-router`) on the screen the user will start from, or in the
   shell in `src/routes/__root.tsx`. A screen with no link does not exist.
3. If the screen needs data, add the server function first — see `add-table`.
4. Run `bash verify.sh`.

## Rules

- shadcn components only (`npx shadcn@latest add <name>`); never hand-roll UI.
- Data only through a server function in `src/server/`; never import `@/db`
  from a component.
- Never edit `src/routeTree.gen.ts`, config files, dependencies or the server.
