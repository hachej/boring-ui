# Project templates

Copy only the artifacts needed for the current stage into a separate project workspace. These documents can be sections in one file for a small project. Do not make the user complete every template before useful work can begin.

| Template | Purpose |
| --- | --- |
| [01 — Brief](01-brief.md) | Problem, people, outcome, constraints |
| [02 — Evidence](02-evidence.md) | Individual observations and reported claims |
| [03 — Domain model](03-domain-model.md) | Vocabulary, data, judgments, rules, examples |
| [04 — Opportunity and scope](04-opportunity-and-scope.md) | Alternatives, first slice, exclusions |
| [05 — Experiment](05-experiment.md) | Assumption, test, result, decision |
| [06 — Product spec](06-product-spec.md) | Required behavior, quality, checks |
| [07 — Boring UI spec](07-boring-ui-spec.md) | Verified implementation mapping |
| [08 — Backlog](08-backlog.md) | Buildable slices and dependencies |
| [09 — Acceptance and launch](09-acceptance-and-launch.md) | Test results, access, task trial, operations |
| [10 — Session state](10-session-state.json) | Resume the interview without repetition |
| [11 — Decisions](11-decisions.md) | Chosen scope, rationale, changes, uncertainty |
| [12 — User profile](12-user-profile.json) | Correctable technical comfort, desired involvement, and explanation preferences, stored privately |

Use `TBD` for unknowns and record who or what can resolve them. A proposed target is not a measured baseline. Blank templates are not build-ready specifications. Fields can be omitted with a stated reason when they do not apply.

IDs are stable within one project. When moving records across projects, prefix them with a project identifier. Never use a method source such as `S04` as customer evidence such as `E-004`.

For profile fact fields, evidence labels, and reuse rules, read [user profiling](../../references/user-profile.md). Link each participant's profile path and revision from session state; keep product-audience hypotheses separate from facts about the interviewee.
