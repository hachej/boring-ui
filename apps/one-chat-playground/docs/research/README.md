# Research notes

Short, dated notes on products we compared One Chat against. Each note ends
with the decision we took and why. Written 2026-09-15.

- [Val Town](val-town/README.md) — per-app server runtime, per-app SQLite on a service, git-like versions. Closest to our infrastructure shape.
- [Shopify Quick](shopify-quick/README.md) — folder + URL + shared services for a trusted internal audience. Closest to our hosting economics.
