# Readable request titles

## Need
OPEN-ISSUES 7: the compact list cuts a long original need at six words, often mid-sentence. Concise localized titles must be authored as `display`, not fabricated by chopping prose.

## Contract
Prefer nonempty authored display; otherwise show the complete original title. Normalize whitespace only. Never mutate the original title/spec/record. Retain exactly one product chip, authorized actions and native detail. No props, operator-board, PM-panel or authorization changes.

## Proof
Public fail-first card tests cover English/French fallback and legacy display, empty display, whitespace and unchanged frozen inputs. Real phone fixture must show the entire legacy title, one chip and no horizontal overflow. Library evidence is not actual Studio adoption.
