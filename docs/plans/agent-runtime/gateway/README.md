# Gateway

This area covers the AgentGateway: the one frozen contract and one
construction path every consumer (workspace, core, CLI, playground,
delegation) talks to when it wants to start or resume an agent session.

## Files

- `plan.md` — the #909 AgentGateway v0 spine plan.
- `AH0-ASSEMBLY-AUDIT.md` — the pre-implementation assembly/consumer audit.
- `ORCHESTRATOR-PROMPT.md` — the execution orchestrator prompt used to run
  the #909 bead graph.

## Status

`plan.md` is the AgentGateway spine plan (state ready-for-human, last updated
2026-07-23). The v0 gateway SHIPPED in v0.1.91 and is recorded as Decision 29
in `docs/DECISIONS.md` (accepted 2026-08-08) — the plan doc predates the
shipped state.
