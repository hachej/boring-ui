Finish a Factory epic after its PR merges

A guarded Orchestrator action turns a verified GitHub merge into closed Beads, stopped runtime resources, optional cleanup, and one final owner acknowledgement.

Author: Orchestrator · 2026-09-03 · Issue #1517 · Epic factory-epic-closure-jgcj

Proposed architecture

flowchart LR
  T[Supervision tick] --> S[factory_status]
  S -->|gh pr view branch| G[GitHub]
  G -->|MERGED metadata| O[Orchestrator]
  O --> C[close_epic preflight]
  C --> D[Stop demos]
  D -->|all children must succeed| B[Close/reuse Beads]
  B --> X[Guarded branch + all snapshots]
  X --> E[Close epic]
  E --> U[Stop calling supervision last]
  U --> R[Complete or partial receipt]
  R -->|complete only| A[[Feature Name] Done]

Goals

  • Observe the epic PR without making ticks brittle.
  • Fail closed before any destructive action.
  • Close children before the epic.
  • Leave an auditable cleanup receipt.
  • Tell the owner the epic is done.

Non-goals

  • Merge PRs automatically.
  • Change Gate 2 approval.
  • Edit canonical .agents/skills.
  • Close unrelated Beads.
  • Delete local/current/main branches.

Decisions

DecisionChosenWhy
AuthorityGitHub branch PRLocal git cannot prove merge.
Unavailable ghpr: null + lookup status; closure refusesObservation stays live; mutation fails closed.
Retry safetyPreflight + idempotent phasesPartial failures can resume without duplicated damage.
CleanupDefault true; same-repo/ref/force-with-lease guardedNormal finish leaves no debt without risking reused refs.
Policy locationHost appendix onlyOwner explicitly excludes canonical skills.
