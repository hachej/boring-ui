Boundary: canonical Workspace still owns Seats, Threads, Mounts, shared state, and artifacts. The internal ConsoleCollection is personal host/control-plane saved navigation metadata, displayed as Project and explicitly not ported as a V2 noun. It has no grants, runtime, cwd, credentials, or origin-record ownership.

Goals / Non-goals

GoalsNon-goals
  • One persistent CLI and hosted Console contract
  • Server-side authorized global inventory
  • Project/Agent/Task/flat organization modes
  • Organizational Session assignment and movement
  • Per-target Automation authorization and Runs
  • No new V2 kernel noun
  • No cross-Workspace Thread migration
  • No canonical Task database
  • No caller-selected runtime/credentials
  • No all-Workspace runtime prewarm
