Design decision

OptionDecisionReason
Freeze every agent editReject as general behavior; adopt conflict-only freezeNo reliable pre-write path lease exists. Freezing after a clean write adds friction; freezing dirty conflict prevents loss.
Classic reload-if-clean / conflict-if-dirtyChooseFits the existing state machine, repairs the exact unsupported gap, and preserves plain-file agents.
TipTap + Yjs collaborationDeferNo Yjs stack exists. It requires server document authority, CRDT persistence/compaction, awareness, and Markdown↔CRDT reconciliation behind ordinary file writes.
