Feature [Epic Closure]: today nothing ends an epic after the owner approves Gate 2. Add epic closure to apps/factory-playground so that once the epic PR is merged the Factory finishes the epic by itself. Three slices, in dependency order:
1. [Epic Closure] Detect merge and close Beads — in the supervision tick path (supervisionPlugin.ts / delegatePlugin.ts factory_status) detect that the epic PR for the epic branch is MERGED (use `gh pr view <branch> --json state,mergedAt,mergeCommit` from the workspace root; tolerate gh absence), and expose it in factory_status as `pr: { number, url, state, mergedAt }`. Add an Orchestrator-only host tool `close_epic` ({ prNumber }) that verifies the PR is merged, closes every Bead labelled epic:<key> with `br close <id> --reason "[Feature Name] shipped in PR #<n> (<merge sha>)"`, closes the epic Bead last, stops any demo via the demo registry, and stops supervision for the calling session; returns a JSON receipt. Unit tests with fakes.
2. [Epic Closure] Clean up branch and snapshot — extend close_epic: after Beads are closed, delete the remote epic branch (`git push origin --delete <branch>`, skip if it is the current branch of the app checkout or if it is main) and invalidate the epic's snapshot registry entry; both optional via { cleanup: true } default true; record what was done in the receipt. Depends on 1.
3. [Epic Closure] Owner summary in the Inbox — after close_epic succeeds the Orchestrator raises `ask_user` titled `[Feature Name] Done` (single acknowledge radio) whose context first line is one sentence, followed by PR URL, merge SHA, closed Bead ids, cleanup performed, and sessions involved; document this as the third gate in the owner-gate skill precedence appendix of factoryFleet.ts (host appendix text only; do not edit .agents/skills). Depends on 1; may run in parallel with 2.
Proof for each slice: `pnpm exec tsc --noEmit` and `pnpm exec vitest run` in apps/factory-playground, run in the dedicated exact-SHA sandbox. Slices 2 and 3 are independent of each other and should be pulled by two different Workers.
