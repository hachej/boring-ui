# Examples

One recipe per block or integration: a small host that mounts it, with a scripted journey.

Run one with its npm script (`npm run slice:journey` for the live-slice browser journey with a real model, `npm run ambient`, `npm run app-shell`, `npm run dock-app`, `npm run workspace-app`, `npm run bot`, `npm run morning`, ...); `<name>:journey` drives it in a real browser with a scripted model.
Deployable hosts are in [`hosts/`](hosts/README.md). Scripted no-UI proofs are in [`../fixtures`](../fixtures/README.md) and the studio playground is in [`../lab`](../lab/README.md).
Build first with `npm run build`; use fictional data only.
