- **0.6.0 is a version-only minor bump that marks the breaking changes already published in 0.5.25 (no code change).** Those are: stores a Pi 1.6.0 Harness writes cannot be opened by an older Harness (one-way), `askPerson` resolves to `{ answer }` or a park the tool must return, and the new `boring-ui-blocks design` rules fail an app at its next kit bump until it is migrated. Apps should move from `^0.5` to `^0.6` deliberately, after reading `# Migrating to 0.5.25` below; the `^0.5` range no longer takes new releases.
