- **`pi-chat`, `pi-chat-markdown`, `app-shell`: `resolveLink` for Markdown links (additive).** `PiChat` (so `AgentWorkspace chat` and `AgentChat chatProps`) takes an optional `resolveLink(href, { source, text, title })`; `Markdown` takes `resolveLink` and `linkSource`, and `ChatTextPart` carries `resolveLink`. It returns an address, `{ href, target?, onClick? }`, `null` (the words, no link) or `undefined` (unchanged). A result still has to be a plain http(s) URL (nothing wider than before); anything else renders as text. The app shell's Markdown note in the pane uses `agent.chatProps.resolveLink` with `source: 'viewer'`. Without it nothing changes. Re-run `npx boring-ui-blocks update` to adopt it.
