- **`pi-chat`, `pi-ambient`, `pi-app`: the chat hooks come from the kit (no behaviour change; the three files are deprecated).** `useChatDraft`, `useConversations`, `useConversationsClient`, `useRemoteChat`, `useChatPlacement` and `readChatPlacement` are implemented once, in `@hachej/boring-ui-kit/chat-react`. The blocks import them from there, and `pi-chat/use-chat-draft.ts`, `use-conversations.ts` and `use-remote-chat.ts` are one-line re-exports kept for one release (an app that copied them keeps working). Do: replace `import { useRemoteChat } from './components/pi-chat/use-remote-chat'` (and the draft and conversations twins) with `import { useRemoteChat } from '@hachej/boring-ui-kit/chat-react'`, make sure `@hachej/boring-ui-kit` is at this release, then delete your copies of the three files (a copy that still holds the old logic keeps its old behaviour and misses kit fixes). Reinstall with `boring-ui-blocks add pi-chat pi-ambient pi-app`. Test: `test/contracts/pi-chat-no-chat-logic-copy.test.mjs`.
