- **Offline libraries are the host's list: `InteractiveHtml.libraries` is the complete set, d3 is no longer built in (`viewer-frame`, `@hachej/boring-ui-kit/offline-libs`; BREAKING, next release is a minor).** `offlineLibraries` is removed; `d3Library` is the vendored d3 7.9.1 as an ordinary export, and `withOfflineLibraries(list)` only validates the host's list (no built-in name clash). Omitted `libraries` means no libraries: a page declaring `<!-- lib: d3 -->` now shows `Unknown library "d3". Available: (none).` An app that relied on built-in d3 must list it. Before: `<AgentWorkspace interactive={{ scriptSources }} />` (d3 available). After: `import { d3Library } from '@hachej/boring-ui-kit/offline-libs'; <AgentWorkspace interactive={{ scriptSources, libraries: { d3: d3Library } }} />`. The same `libraries` prop goes through `HtmlPane`, the `pi-app` viewers and `ViewerOptions.interactive`. A host that never imports `d3Library` no longer bundles d3. Re-add the `viewer-frame` block.
