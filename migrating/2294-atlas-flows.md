- **`atlas`: flows you can check on a live app (additive).** New step verbs `expect <text>` (it appears) and `absent <text>` (it is not on the page), and an optional time on any text check (`wait 90s "Terminé"`, up to 10 minutes) for an agent's run. New options: `--only <flow or state>` (repeatable) runs one workflow, `--quick` shoots desktop light only, `--steps` keeps the page after each step (the run's `states[].steps`). A failed state now keeps its screen and reason (`states[].failure: { viewport, mode, at, reason, file }`), and the run prints `✔ state <id>` / `✖ state <id> …`. Nothing to change in an existing manifest.
