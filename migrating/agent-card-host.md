- **`agent-card`: a host can draw its own header and body, put the tray inside it, and make the chat on the first tap (additive).** New optional props: `header` (drawn in place of the built-in header, not a tap target of the card), `children` (the host's body, under the header and `meta`), `slot` (an element inside that body: the folded card's composer and the tray are drawn there, and return under the header, state kept, when it goes), `controller` is now optional with `onChatRequest` (no controller: the strip shows only « Open the chat », no chat is mounted, and a tap calls `onChatRequest` once; the composer opens when the controller arrives), `composer` and `onComposerChange` (a host gesture can open the folded card's composer) and `unread` (a quiet dot on the folded card, with no count, even before any controller exists). Without these props the card is unchanged. Update the block with `npx boring-ui-blocks add agent-card`; nothing else to do.
