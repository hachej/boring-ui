- **Waits park in Pi 1.6.0 instead of watching a document (`agent`; same behaviour; stored waits keep working).** `ask_user`, `requireApproval`, browser tasks, `present` with `ack`, schedules and native questions no longer hold a running call or phase that watches a document and runs its own timer: the call returns a Pi park (`{ sleep: { until, signals } }`) and the answer, the deadline or a cancel wakes it. Stores written before this with a pending question, browser task, view, schedule or native question open and settle through the same answer functions. What an app changes, only if it called these helpers itself: `askPerson` (`@hachej/boring-agent/ask-user`) resolves to `{ answer }` or the park the tool must return (`if (!('answer' in asked)) return asked;`) and a tool that calls it sets `cancel: cancelQuestion` (new export) so stopping the conversation cancels the pending question. `answerUserQuestion`, `answerBrowserTask`, `answerViewOpen`, `askUserQuestionId` and `browserTaskId` are unchanged. No kit consumer (`chase`, `studio`, `coach-max`, `clinic`) calls `askPerson`.
