- **`@hachej/boring-files/workspace`: `createWorkspaceProvider({ followLinks: true })` (additive, off by default).** A disk workspace's listing, search and change polling skip symbolic links unless this is set. With it, a link to a file or directory is walked when its real target stays inside the workspace root, and what is under it is reported by the link's path; a link that escapes the root, dangles or loops back is ignored without an error. Writes never go through a link itself. No change unless an app sets the option.
