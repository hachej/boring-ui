- **`s3SkillSource`: a `validate` hook, `lastRejected()`, a flexible `layout`, and a cheap check; `load_skill` re-checks a versioned source on a miss (`@hachej/boring-agent/agents`; additive).** `validate(files, context, version)` sees each fetched file (`{ path, text, sha256 }`) and may return a reason or throw to refuse the whole set (the last good set stays). `source.lastRejected()` returns `{ version?, at, reason, files? }` for the last refused set, whatever the cause, and clears when a later set is accepted; `lastRefreshed().failed` is unchanged. `layout: { manifestKey?, fileKey?(version, path) }` puts the manifest and files elsewhere under the prefix (keys checked for `..` and a leading `/`); the default layout is unchanged. The source now reads only `current.json` while it is unchanged (before, every `maxAgeMs` check fetched every file), and a `load_skill` miss on any versioned source reads the pointer once; a pinned conversation stays on its version and the answer names the newer one. Nothing to do unless you want these.
